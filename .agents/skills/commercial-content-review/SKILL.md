# commercial-content-review

1. Free должен быть полезен (промпты + DESIGN/TOKENS/AGENT + tokens) — не «пустышка».
2. Full-only материалы не в free definition.
3. Нет бинарных шрифтов/стоков без лицензии в ZIP.
4. UI Full Pack — честно «in development», без fake checkout.
5. Сверить [PRODUCT_ENTITLEMENTS.md](../../../docs/PRODUCT_ENTITLEMENTS.md).
