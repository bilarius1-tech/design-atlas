# Devlog — журнал разработки

Короткий хронологический лог того, что реально сделано в репозитории.

## Правила

1. Одна запись на календарный день: `YYYY-MM-DD.md` (при необходимости — несколько секций внутри).
2. Писать по факту: что сделали, что проверили, что осталось, риски.
3. Не дублировать целиком CHANGELOG — здесь рабочий контекст для людей и агентов.
4. В конце сессии (или после фазы) — обновить сегодняшний файл.
5. Открытие/закрытие дня (фокус + handoff): [sessions/](../sessions/) + шаблоны [DAY-OPEN](../templates/DAY-OPEN.md) / [DAY-CLOSE](../templates/DAY-CLOSE.md).
6. Язык: русский; технические имена файлов/команд — как в репозитории.

## Шаблон секции

```md
## HH:MM · Краткий заголовок

- **Фаза:** PHASE N / P0…
- **Сделано:** …
- **Проверки:** `pnpm …`
- **Файлы:** ключевые пути
- **Осталось / next:** …
```
