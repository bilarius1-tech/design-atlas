# Research notes · bento-grid

## Intent

Bento-box tile atmosphere for DESIGN ATLAS — queue #14. Owned SSOT: dizain-prompty `bento-grid`. **Atmosphere only** — no Studio freeform grid editor. Uneven tile language (1×1 / 2×1 / …) expressed in preview CSS + prompts, not a page builder.

## Traits

- Ground `#F5F5F7`, ink `#1D1D1F`, blue `#0A84FF`, yellow tile `#FFD60A`
- Soft white tiles, radius ~24px, **gap 16px** (air — not dense-tile flush)
- Type: Inter / Manrope / Onest
- One thought per tile; 1–2 colored accent tiles

## Differentiation

| Axis | Dense-tile industrial | Bento grid |
|------|----------------------|------------|
| Gap | `0px` flush | `16px` air |
| Radius | often 0 | ~24px soft |
| Stage | dark metal / blueprint | light Apple-gray |
| Editor | n/a | **no** Studio grid editor |

## Anti-patterns

- Building a bento layout editor in Studio
- Applying `gap: 0` flush mosaics by default
- Neo-brutal hard offsets as the system
- Crowding every tile with paragraphs
