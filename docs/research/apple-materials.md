# Research notes · apple-materials

## Intent

Apple-like materials / HIG-adjacent web system for DESIGN ATLAS — standard platform pack. Cite Apple HIG materials concepts; **do not** copy SF Pro binaries or DesignPrompts packs. Atlas-original tokens + RU/EN prompts.

## Traits

- Light gray ground `#F5F5F7`, pure white surfaces, ink `#1D1D1F`
- System blue `#0071E3` (web-safe Apple-like CTA)
- Soft continuous corners (~12–22px); subtle elevation
- Type: **Inter** / **Manrope** as SF-adjacent web stand-ins (Cyrillic)
- Translucent / blur optional on chrome; keep readable contrast

## Anti-patterns

- Material tonal seed rainbow as identity
- Hard neo-brutal frames
- Dense-tile flush industrial mosaics
