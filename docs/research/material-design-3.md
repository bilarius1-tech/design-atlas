# Research notes · material-design-3

## Intent

Material Design 3 (Material You) visual system for DESIGN ATLAS — standard platform pack. Cite official MD3 guidance; **do not** copy third-party marketplace packs. Atlas-original RU/EN prompts and demo copy.

## Traits

- Tonal surfaces (surface / surface-container), seed primary
- Shape: 12–28px component radii; pill FABs/buttons where MD3 expects
- Type: Roboto / Google Sans lineage → Atlas uses **Roboto** + **Manrope** (Cyrillic)
- Elevation via tonal layering more than heavy drop shadows
- Default seed: calm blue-violet primary suitable for product UI

## Anti-patterns

- Apple materials / SF Pro as the hero system
- Neo-brutal hard offsets
- Ignoring contrast on tonal containers
