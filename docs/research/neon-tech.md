# Research notes · neon-tech

## Intent

Neon / dark-tech web system for DESIGN ATLAS — next proof after glass. Owned SSOT for palette and vibe: InfoStyle `neon` (product-card catalog by the same author). Adapted here for **landing / app shell** dual prompts, not marketplace image-gen rules.

## Traits

- Deep charcoal ground `#171A22` with soft radial lift
- Controlled neon signals: lime `#B6FF00`, cyan `#00D5FF`, magenta `#FF4FD8`
- Fine grid / contour glow — futuristic but readable
- Display face **Unbounded**; body Oswald/Manrope; mono **Roboto Mono**
- Dark ink on lime CTAs (contrast), light text on ground

## Anti-patterns

- Uncontrolled full-bleed glow that kills type
- Glass frosted panels as the main idea (that’s `glassmorphism`)
- Soft clay / neu extrusion
- Inventing device chrome details in prompts (Atlas = visual system only)
