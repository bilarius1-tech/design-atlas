# Часть I. Философия и продуктовые принципы

## 1. Миссия

Создать серьёзную визуальную библиотеку веб-дизайна, которая помогает человеку осознанно выбирать визуальное направление цифрового продукта и передавать выбранную дизайн-систему AI-агентам для реализации.

Проект объединяет три мира:

1. Визуальную энциклопедию веб-дизайна.
2. Библиотеку UI-компонентов и дизайн-систем.
3. Инструмент подготовки технически точных инструкций для AI coding agents.

Пользователь должен увидеть стиль, изучить визуальную логику, проверить на реальных UI-элементах и получить готовые файлы для разработки.

## 2. Главная философия

DESIGN ATLAS — не генератор сайтов, не маркетплейс шаблонов и не каталог случайных промптов.

Это инструмент передачи визуального замысла от человека к машине.

Основной сценарий:

`ВИЗУАЛЬНОЕ НАПРАВЛЕНИЕ → ИЗУЧЕНИЕ → ПРОВЕРКА → ВЫБОР → DESIGN SYSTEM → AGENT INSTRUCTIONS → РЕАЛИЗАЦИЯ`

Мы не продаём обещание «создать красивый сайт одной кнопкой». Мы помогаем точно объяснить AI-агенту, какой интерфейс создать, почему он должен выглядеть именно так и какие правила нельзя нарушать.

## 3. Продуктовые принципы

### 3.1 Visual First

Сначала визуальный результат, потом описание. У каждого стиля — полноценная демонстрационная страница. Карточки с цветными квадратиками недостаточно.

### 3.2 Design System First

Стиль — не набор цветов. Описание включает философию, композицию, типографику, цвет, сетку, интервалы, геометрию, компоненты, состояния, анимации, адаптивность, правила и анти-паттерны.

### 3.3 Agent Ready

Для каждого стиля обязательны:

- промпт RU;
- промпт EN;
- `DESIGN.md`;
- `TOKENS.md`;
- `AGENT-INSTRUCTIONS.md`;
- структурированные данные дизайн-системы.

Промпт — проверяемые инструкции, не художественное эссе.

### 3.4 Human Control

AI не придумывает визуальную концепцию вместо пользователя. Человек выбирает, решает и контролирует.

### 3.5 No AI Slop

Запрещено: случайные градиенты; одинаковые rounded-карточки повсюду; декоративные иконки без смысла; фальшивая статистика; стандартный AI-hero; Inter как авто-выбор для всех направлений; одинаковая композиция всех демо.

### 3.6 Editorial Quality

Оболочка продукта — редакционный интерфейс: сильная типографика, сетка, плотность, иерархия, минимум шума. Не каждая область — отдельная карточка.

### 3.7 Content Integrity

Направления содержательны и оригинально описаны. Сторонние проекты — только как референсы. Без копирования закрытого контента, ТМ и чужих материалов без проверки прав.

## 4. Аудитория

UX/UI · веб-дизайнеры · AI-разработчики · продуктовые команды · начинающие дизайнеры.

## 5. Позиционирование

`DESIGN ATLAS — Visual Design Systems for Humans and AI Agents.`

RU: «Выбери визуальный стиль. Изучи его. Передай своей AI-команде готовую дизайн-систему».

## 6. Чего мы НЕ делаем

- Визуальный конструктор сайтов.
- Универсальный AI-генератор интерфейсов.
- Каталог AI-инструментов.
- Платная библиотека текстовых промптов без демонстраций.
- Копирование примеров без самостоятельной реализации.
- Смешивание стилей в одной демо без причины.
- Генерация промпта из случайных текстовых шаблонов.

## 7. Принцип качества публикации

Стиль публикуется только после проверки:

1. Визуальная самостоятельность  
2. Полнота дизайн-системы  
3. Качество demo  
4. Согласованность компонентов  
5–6. Качество RU/EN промптов  
7. Корректность `DESIGN.md`  
8. Desktop / tablet / mobile  
9. A11y и контраст  
10. Реализуемость другим AI-агентом  

Иначе статус остаётся `draft`.
