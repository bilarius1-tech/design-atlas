# Часть VI. UX и требования приложения

## Маршруты (целевые)

- `/ru` — главная
- `/ru/styles` — каталог
- `/ru/styles/[slug]` — страница стиля
- `/ru/components` — библиотека компонентов
- `/ru/components/[slug]` — страница компонента
- `/ru/glossary` — глоссарий
- `/ru/about` — о проекте

Аналогично для `/en`.

## Главная

Редакционный hero, галерея направлений, популярные стили, вход в компоненты, объяснение экспорта для агентов, примеры файлов, новые/обновлённые стили. Без длинной маркетинговой презентации.

## Каталог

Превью — реальные фрагменты демо, не одинаковые скриншоты шаблона. Режимы Gallery и Compact. Фильтры: категория, плотность, настроение, тип проекта, сложность, light/dark character, типографический характер.

## Страница стиля

Header, философия, визуальная демонстрация, Playground, Typography, Color, Components, Demo Landing, Rules, Use Cases, Prompt & Export, Related. Заметный переход к экспорту.

## Компоненты

Сравнение одного UI-элемента across styles.

## Поиск / сравнение / глоссарий

Поиск RU+EN по названиям, тегам, терминам. Сравнение двух стилей — не в первой итерации. Глоссарий UX/UI с RU/EN, примером и связями.

## A11y / Responsive / SEO

Полноценный mobile, semantic HTML, keyboard, focus, labels, contrast, reduced motion. Уникальные метаданные на стиль; RU — основное SEO-направление.
