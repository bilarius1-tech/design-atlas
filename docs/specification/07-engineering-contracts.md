# Часть VII. Инженерные контракты

## Шаблоны

`docs/templates/TASK-TEMPLATE.md`, `AGENT-REPORT.md`, `ADR-TEMPLATE.md`, `STYLE-REVIEW.md`, `RELEASE-CHECKLIST.md`, `CONTENT-REVIEW.md`.

## Контентные контракты

Автопроверка схем. Запрещены: отсутствующие переводы, битые ресурсы, неизвестные категории/компоненты, некорректные цвета, пустые обязательные поля, дубли ID, рассинхрон версий токенов.

## Генерация файлов

`Style Definition → Export Generator → Markdown → ZIP`  
Детерминированность обязательна. Единый источник токенов — без ручных параллельных копий.

ZIP:

```text
design-atlas/
  DESIGN.md
  TOKENS.md
  AGENT-INSTRUCTIONS.md
  prompts/prompt.ru.md
  prompts/prompt.en.md
  tokens/tokens.json
  README.md
```

## Проверка промптов

Философия, цвет, типографика, сетка, размеры, компоненты, состояния, адаптив, запреты, критерии результата. RU и EN одинаковы по смыслу и полноте.

## Версии и наблюдаемость

Версия на стиль + CHANGELOG. Логи ошибок, битые ссылки, размер изображений, ошибки экспорта. Не собирать лишние пользовательские данные.

## Финальный критерий

Ни один агент, стиль или демо не определяет архитектуру всего приложения.
