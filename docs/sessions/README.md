# Sessions — открытие и закрытие дня

Ежедневный handoff между сессиями. Не заменяет [devlog](../devlog/) (хроника) и не заменяет [CHANGELOG](../../CHANGELOG.md) (релизная заметка).

| Тип | Шаблон | Файлы |
|-----|--------|--------|
| Открытие | [DAY-OPEN.md](../templates/DAY-OPEN.md) | `YYYY-MM-DD-open.md` |
| Закрытие | [DAY-CLOSE.md](../templates/DAY-CLOSE.md) | `YYYY-MM-DD-close.md` |

## Ритуал

1. **Утро / старт:** скопировать DAY-OPEN → заполнить → выбрать один outcome.
2. **Вечер / стоп:** скопировать DAY-CLOSE → заполнить → commit/push по запросу.
3. Завтрашний open начинается с чтения вчерашнего close.
