# Промпт для конструктора · poster-brutal

Ты собираешь лендинг (или сайт) в **конструкторе страниц** (Тильда, LPmotor, Creatium, Kraftum и аналоги) либо через агента конструктора.
Источник визуальной системы: DESIGN ATLAS · **Poster Brutal** (`poster-brutal`).

## Главное правило

Не изобретай вторую дизайн-систему. Повтори эту. Atlas не конструктор — ты применяешь готовую систему к блокам пользователя.

## Токены (обязательны)

- Фон `#F3F1EA`, поверхность `#FFFFFF`, текст `#0A0A0A`, приглушённый `#3F3F3F`
- Primary `#0A0A0A`, accent `#FF4D00`, border `#0A0A0A`
- Радиус `0px`, толщина линии `3px`, тень `6px 6px 0 #0A0A0A`
- Шрифт заголовков: `Arial Black, Impact, Haettenschweiler, sans-serif`
- Шрифт текста: `Arial, Helvetica, sans-serif`
- Базовый размер текста: `18px`, display: `88px`
- Ритм: unit `8`, секции ~`104px`, контейнер ~`1080px`

## Как накладывать на блоки конструктора

1. **Шапка:** логотип/марка, 3–5 ссылок, вторичная кнопка «Войти», primary CTA.
2. **Hero:** заголовок + короткий текст + две кнопки (primary + secondary) + медиа/макет продукта.
3. **Метрики:** 3–4 числа в ряд, без фальшивой «магии».
4. **Возможности:** 3 карточки; радиус и тень только из токенов.
5. **Тарифы / FAQ / форма:** поля и кнопки с тем же border/radius; accent — для главного действия формы.
6. Межсекционные отступы крупные и ровные.

## Запреты

- Soft shadow / blur / glassmorphism
- Pastel rounded cards
- Inter as a silent default
- Rainbow accents instead of one signal
- Stickers over hero media

## Проверка перед публикацией

1. Цвета и радиусы совпадают с токенами выше.
2. Нет второй палитры «на вкус».
3. Кнопки и поля выглядят как одна семья.
4. На мобиле нет горизонтального скролла.
5. Контент пользователя уникален — меняется текст/фото, не система.
