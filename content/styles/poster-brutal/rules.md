# Rules · poster-brutal

## Do

1. Lead with oversized heavy type before adding color.
2. Keep borders at 3px and radius at 0.
3. Use hard offset shadows only (`6px 6px 0 #0A0A0A`).
4. Reserve orange accent for critical CTA / signal.
5. Leave generous poster-like negative space.

## Don’t

1. Don’t soften into rounded pastel cards or blur shadows.
2. Don’t default to Inter or script faces.
3. Don’t cover hero media with sticker badges.
4. Don’t rainbow the palette — one accent is enough.
5. Don’t claim this is a scrape/import of third-party packs.

## Composition

- Default composition id: `editorial-split`
- Studio compare keeps template copy constant across styles
- Markdown must mirror `tokens.json`

## Accessibility

- Maintain AA contrast for text pairs
- Visible focus rings
- Respect `prefers-reduced-motion`
