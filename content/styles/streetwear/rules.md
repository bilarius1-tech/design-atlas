# Rules · streetwear

## Do

1. Peach ground `#FFF3E8`, near-black ink `#211C1A`.
2. Coral primary CTAs; lime and violet as poster accent blocks.
3. Unbounded for display; Oswald/Roboto for body with Cyrillic.
4. Hard offset shadow + thicker borders (`2px`).
5. Short headlines; campaign energy without sticker clutter.

## Don’t

1. Don’t drift into soft clay / neu / glass.
2. Don’t copy `poster-brutal` hard constructivist black slabs as the whole system.
3. Don’t invent logos, fake brand marks, or random stickers.
4. Don’t use thin gray body on peach.
5. Don’t invent a second palette outside `tokens.json`.

## Composition

- Default: `modular-stack`
- Structure from user chat; Atlas = visual system only
- Preview may add a diagonal accent band via scoped CSS

## Accessibility

- Coral CTAs: verify label contrast (usually white or near-black)
- Lime blocks: prefer dark ink on `#C7F000`
- Focus-visible on high-energy controls
