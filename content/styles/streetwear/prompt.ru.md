# Промпт · streetwear

Ты реализуешь интерфейс в стиле **Streetwear** по системе DESIGN ATLAS.

## Контекст

- Тёплый персиковый фон, крупный Unbounded display, плакатные акценты coral / lime / violet.
- Структура страницы уже в чате пользователя — здесь только визуальная система.

## Обязательные токены

- background `#FFF3E8`, surface `#FFFFFF`, text `#211C1A`, muted `#6B635E`
- primary `#FF5A36`, accent `#C7F000`, accentSecondary `#6246EA`, border `#211C1A`
- radius `8px`, radiusButton `999px`, radiusCard `12px`, borderWidth `2px`
- shadow `6px 6px 0 #211C1A`
- container `1100px`, display `57px`, base `16px`
- fonts: Unbounded headings; Oswald/Roboto/Manrope body

На lime-плашках — тёмный текст. Энергия через плоскости и тип, не через случайные стикеры.

## Запреты

- Clay / neu / glass
- Полный сдвиг в `poster-brutal` constructivism
- Фейковые логотипы и наклейки
- Вторая палитра «на вкус»

## Критерии приёмки

1. Peach + Unbounded + три сигнала читаются сразу.
2. Контраст CTA в порядке.
3. Значения = `tokens.json`.
4. Структура пользователя не переписана.
