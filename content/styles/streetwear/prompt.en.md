# Prompt · streetwear

Implement an interface in the **Streetwear** style using the DESIGN ATLAS system.

## Context

- Warm peach ground, dense Unbounded display, coral / lime / violet poster accents.
- Page structure comes from the user’s chat — this prompt is visual system only.

## Mandatory tokens

- background `#FFF3E8`, surface `#FFFFFF`, text `#211C1A`, muted `#6B635E`
- primary `#FF5A36`, accent `#C7F000`, accentSecondary `#6246EA`, border `#211C1A`
- radius `8px`, radiusButton `999px`, radiusCard `12px`, borderWidth `2px`
- shadow `6px 6px 0 #211C1A`
- container `1100px`, display `57px`, base `16px`
- fonts: Unbounded headings; Oswald/Roboto/Manrope body

On lime blocks use dark text. Energy comes from planes and type — not random stickers.

## Bans

- Clay / neu / glass
- Full collapse into `poster-brutal` constructivism
- Fake logos and stickers
- A second “taste” palette

## Acceptance

1. Peach + Unbounded + three signals read immediately.
2. CTA contrast holds.
3. Values match `tokens.json`.
4. User structure is not rewritten.
