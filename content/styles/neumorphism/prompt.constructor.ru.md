# Промпт для конструктора · neumorphism

Ты собираешь лендинг в **конструкторе** (Тильда, LPmotor, Creatium, Kraftum и аналоги).
Источник: DESIGN ATLAS · **Neumorphism** (`neumorphism`).

## Главное правило

Блоки уже заданы пользователем. Atlas даёт только визуальную систему.

## Токены

- Фон/поверхность `#E6EBF2`, текст `#2E3440`, muted `#6B7380`
- Accent/primary `#3D5AFE`
- Радиус кнопок `16px`, карточек `20px`, border `0`
- Тень: `8px 8px 16px #C3CAD5, -8px -8px 16px #FFFFFF`; pressed — inset pair
- Шрифт Manrope (кириллица); иначе системный аналог
- Display `57px`, base `16px`, контейнер `1120px`

## Наложение на блоки

1. Карточки того же цвета, что фон; объём тенью.
2. Primary button — indigo; secondary — soft extruded без сильной заливки.
3. Не меняй структуру секций.

## Запреты

- Clay pastel / neo-brutal
- Тёмная neon-консоль
- Вторая палитра «на вкус»
