## Core rule

Blocks are already set by the user. Atlas supplies the visual system only.

## Tokens

- Background/surface `#E6EBF2`, text `#2E3440`, muted `#6B7380`
- Accent/primary `#3D5AFE`
- Button radius `16px`, card radius `20px`, border `0`
- Shadow: `8px 8px 16px #C3CAD5, -8px -8px 16px #FFFFFF`; pressed = inset pair
- Font Manrope (Cyrillic); else closest system analog
- Display `57px`, base `16px`, container `1120px`

## Map onto blocks

1. Cards match the ground; volume from shadow.
2. Primary button indigo; secondary soft extruded without heavy fill.
3. Do not change section structure.
