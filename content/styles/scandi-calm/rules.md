# Rules · scandi-calm

## Do

1. Warm white ground `#F1EEE7`, ink `#35342F`.
2. Clay `#B57956` for primary; sage/slate sparingly.
3. Manrope for display and body — calm, friendly, Cyrillic.
4. Soft radii, airy gaps, simple geometric planes.
5. Daylight calm — comfort without clutter.

## Don’t

1. Don’t apply dense-tile / industrial 0-gap mosaics.
2. Don’t lead with Playfair fashion-journal energy (soft-editorial).
3. Don’t invent hygge clutter, fake wood noise, or stickers.
4. Don’t drift into neon / streetwear / signal yellow.
5. Don’t invent a second palette outside `tokens.json`.

## Composition

- Default: `modular-stack`
- Structure from user chat; Atlas = visual system only
- Preview may add soft daylight wash via scoped CSS

## Accessibility

- Ink on warm white ≥ AA
- Clay CTAs: cream/white labels
- Respect `prefers-reduced-motion`
