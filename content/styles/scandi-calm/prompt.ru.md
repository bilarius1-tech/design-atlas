# Промпт · scandi-calm

Ты реализуешь интерфейс в стиле **Scandi Calm** по системе DESIGN ATLAS.

## Контекст

- Спокойный скандинавский веб: тёплый белый, воздух, Manrope, мягкие натуральные акценты.
- Структура страницы уже в чате пользователя — здесь только визуальная система.

## Обязательные токены

- background `#F1EEE7`, surface `#FAF8F3`, text `#35342F`, muted `#6F6D66`
- primary `#B57956`, accent `#7D8C72`, accentSecondary `#7A8FA3`, border `#DDD8CE`
- radius `10px`, radiusButton `999px`, radiusCard `14px`, borderWidth `1px`
- soft shadow; container `1100px`; display `57px`; base `16px`
- fonts: Manrope headings/body

Воздух важнее декора. Не dense-tile. Не fashion-Playfair как герой.

## Запреты

- Dense-tile / industrial
- Soft-editorial Playfair-lead drift
- Neon / streetwear
- Hygge-шум и фейковые фактуры
- Вторая палитра «на вкус»

## Критерии приёмки

1. Warm white + Manrope + soft naturals читаются сразу.
2. Контраст CTA в порядке.
3. Значения = `tokens.json`.
4. Структура пользователя не переписана.
