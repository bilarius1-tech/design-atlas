# Prompt · scandi-calm

Implement an interface in the **Scandi Calm** style using the DESIGN ATLAS system.

## Context

- Calm Scandinavian web: warm white, air, Manrope, soft natural accents.
- Page structure comes from the user’s chat — this prompt is visual system only.

## Mandatory tokens

- background `#F1EEE7`, surface `#FAF8F3`, text `#35342F`, muted `#6F6D66`
- primary `#B57956`, accent `#7D8C72`, accentSecondary `#7A8FA3`, border `#DDD8CE`
- radius `10px`, radiusButton `999px`, radiusCard `14px`, borderWidth `1px`
- soft shadow; container `1100px`; display `57px`; base `16px`
- fonts: Manrope headings/body

Air over decoration. Not dense-tile. Not fashion-Playfair as the hero.

## Bans

- Dense-tile / industrial
- Soft-editorial Playfair-lead drift
- Neon / streetwear
- Hygge clutter and fake textures
- A second “taste” palette

## Acceptance

1. Warm white + Manrope + soft naturals read immediately.
2. CTA contrast holds.
3. Values match `tokens.json`.
4. User structure is not rewritten.
