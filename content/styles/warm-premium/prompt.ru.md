# Промпт · warm-premium

Ты реализуешь интерфейс в стиле **Warm Premium** по системе DESIGN ATLAS.

## Контекст

- Тёплый тёмный stage, Playfair display, дозированное золото.
- Структура страницы уже в чате пользователя — здесь только визуальная система.

## Обязательные токены

- background `#26211F`, surface `#322C29`, text `#F3EDE2`, muted `#B8A99A`
- primary `#C7A66A`, accent `#D6B7B0`, accentSecondary `#8DAF9D`, border `#4A403A`
- radius `10px`, radiusButton `999px`, radiusCard `14px`, borderWidth `1px`
- shadow soft dark; container `1080px`; display `57px`; base `16px`
- fonts: Playfair Display headings; Manrope body

На золотых CTA — тёмный текст. Без фейковых наград и логотипов.

## Запреты

- Neon / streetwear / clay
- Блёстки и выдуманные seals
- Вторая палитра «на вкус»

## Критерии приёмки

1. Тёплый dark + Playfair + sparingly gold читаются сразу.
2. Контраст CTA в порядке.
3. Значения = `tokens.json`.
4. Структура пользователя не переписана.
