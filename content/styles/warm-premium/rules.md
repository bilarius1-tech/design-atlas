# Rules · warm-premium

## Do

1. Warm dark ground `#26211F` with cream ink `#F3EDE2`.
2. Gold `#C7A66A` for primary CTAs; blush/sage as soft secondary signals.
3. Playfair Display for headings; Manrope for body with Cyrillic.
4. Soft radii; pill buttons ok; airy section rhythm.
5. Restraint — luxury through material calm, not glitter.

## Don’t

1. Don’t invent awards, seals, logos, or “heritage” claims.
2. Don’t flood gold across every surface.
3. Don’t drift into neon / streetwear / clay.
4. Don’t use thin low-contrast gray on dark warm ground.
5. Don’t invent a second palette outside `tokens.json`.

## Composition

- Default: `modular-stack`
- Structure from user chat; Atlas = visual system only
- Preview may add warm radial vignette via scoped CSS

## Accessibility

- Cream on dark ≥ AA
- Gold CTAs: prefer dark label `#26211F`
- Respect `prefers-reduced-motion`
