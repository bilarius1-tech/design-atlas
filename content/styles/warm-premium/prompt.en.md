# Prompt · warm-premium

Implement an interface in the **Warm Premium** style using the DESIGN ATLAS system.

## Context

- Warm dark stage, Playfair display, gold used sparingly.
- Page structure comes from the user’s chat — this prompt is visual system only.

## Mandatory tokens

- background `#26211F`, surface `#322C29`, text `#F3EDE2`, muted `#B8A99A`
- primary `#C7A66A`, accent `#D6B7B0`, accentSecondary `#8DAF9D`, border `#4A403A`
- radius `10px`, radiusButton `999px`, radiusCard `14px`, borderWidth `1px`
- soft dark shadow; container `1080px`; display `57px`; base `16px`
- fonts: Playfair Display headings; Manrope body

Gold CTAs use dark labels. No fake awards or logos.

## Bans

- Neon / streetwear / clay
- Glitter and invented seals
- A second “taste” palette

## Acceptance

1. Warm dark + Playfair + sparing gold read immediately.
2. CTA contrast holds.
3. Values match `tokens.json`.
4. User structure is not rewritten.
