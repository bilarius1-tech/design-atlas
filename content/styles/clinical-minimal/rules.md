# Rules · clinical-minimal

## Do

1. Cool light ground `#F3F7F8`, ink `#24333A`.
2. Steel blue `#4386A8` for primary; teal / soft blue as markers.
3. Manrope (or DM Sans / Roboto) — neutral, readable.
4. Compact information blocks; hairline rules; small radii.
5. Clarity first — no decorative fashion serif.

## Don’t

1. Don’t invent medical approvals, therapies, or clinical certifications.
2. Don’t warm into soft-editorial paper + Playfair.
3. Don’t use neon / streetwear / dense industrial mosaics as the hero.
4. Don’t use thin low-contrast gray on cool light.
5. Don’t invent a second palette outside `tokens.json`.

## Composition

- Default: `modular-stack`
- Structure from user chat; Atlas = visual system only
- Preview may add a faint inset frame via scoped CSS

## Accessibility

- Ink on cool light ≥ AA
- Steel CTAs: white labels
- Respect `prefers-reduced-motion`
