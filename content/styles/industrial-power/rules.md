# Rules · industrial-power

## Do

1. Graphite ground `#252522`, cream ink `#F4F1E9`.
2. Signal yellow `#FFC400` for primary CTAs with **dark** labels.
3. Use composition `dense-tile` + `spacing.gap: 0px` for features/stats mosaics.
4. Oswald for display; hard edges; card radius `0`.
5. Orange/red only as secondary signal markers.

## Don’t

1. Don’t soften into clay / neu / glass.
2. Don’t invent safety seals or industrial certifications.
3. Don’t switch to blueprint cyan engineering as the hero.
4. Don’t add airy soft gaps that break dense-tile.
5. Don’t invent a second palette outside `tokens.json`.

## Composition

- Default: `dense-tile`
- Structure from user chat; Atlas = visual system only
- Preview may add diagonal metal-stripe atmosphere via scoped CSS

## Accessibility

- Dark ink on yellow CTAs
- Cream on graphite ≥ AA
- Respect `prefers-reduced-motion`
