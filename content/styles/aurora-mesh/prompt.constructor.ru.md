# Промпт для конструктора · aurora-mesh

Источник: DESIGN ATLAS · **Aurora Mesh** (`aurora-mesh`).
Блоки уже заданы пользователем — применяй только визуальную систему.

## Токены

- Фон `#0B0A1F`, панели полупрозрачные, текст белый
- CTA `#FFFFFF` с тёмной подписью; cyan `#6EE7F9`, pink `#F472B6`, violet `#A78BFA` в mesh
- Карточки `20px`, кнопки pill, blur `14px`
- Manrope; display `57px`; контейнер `1120px`

## Наложение

1. Ночной stage; сзади 3–4 размытых radial перелива (aurora).
2. Карточки — стекло поверх mesh; CTA белая pill.
3. Без neon-grid и без neo-brutal рамок.
4. Не меняй структуру блоков пользователя.

## Запреты

- Neon-tech / neo-brutal / dense-tile
- Вторая палитра
