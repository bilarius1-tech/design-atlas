# Rules · aurora-mesh

## Do

1. Night ground `#0B0A1F` (or a calm light stage if the brief asks — keep mesh soft either way).
2. Mesh blooms: cyan `#6EE7F9`, violet `#A78BFA`, pink `#F472B6` — large, blurred, overlapping.
3. Manrope for UI type; Unbounded only for short display punches.
4. Translucent cards + light border; white pill CTA with dark `#0B0A1F` ink.
5. Soft glow shadows; optional slow bloom drift with `prefers-reduced-motion` respected.

## Don’t

1. Don’t harden into neon-tech grids or lime outlines.
2. Don’t use neo-brutal 3px black rules / hard offsets.
3. Don’t flatten to a single purple SaaS wash without multi-hue mesh.
4. Don’t apply dense-tile flush mosaics.
5. Don’t invent a second palette outside `tokens.json`.

## Composition

- Default: `modular-stack`
- Structure from user chat; Atlas = visual system only
- Preview CSS may animate mesh orbs; pause under reduced motion

## Accessibility

- White text on `#0B0A1F` ≥ AA
- Dark labels on white CTAs
- Respect `prefers-reduced-motion`
