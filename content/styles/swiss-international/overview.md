# Swiss International Style

International Typographic Style — often called Swiss Style — is a mid-20th-century approach to visual communication built on objectivity, modular structure, and typographic clarity.

## What Design Atlas delivers

This entry is a **digital reference system** for humans and AI coding agents. It translates historical principles into:

- validated tokens (`tokens.json`)
- typography roles
- component matrix
- interactive playground
- demo landing composition
- agent-facing prompts and `DESIGN.md`

It is **not** a claim that a specific 1950s poster is reproduced pixel-for-pixel on the web.

## Visual logic

1. **Grid first** — alignment and modules before decoration.
2. **Type as structure** — hierarchy carries meaning.
3. **Limited color** — ink, paper, signal accent.
4. **Sharp geometry** — radius 0; shadow none.
5. **Honest content** — no fake metrics theater.
