# Constructor prompt · swiss-international

You are assembling a landing (or site) in a **page constructor** (Tilda, LPmotor, Creatium, Kraftum, or similar) or via a constructor agent.
Visual system source: DESIGN ATLAS · **Swiss International Style** (`swiss-international`).

## Core rule

Do not invent a second design system. Reproduce this one. Atlas is not a constructor — you apply a ready system to the user's blocks.

## Mandatory tokens

- Background `#F2F0EA`, surface `#FFFFFF`, text `#111111`, muted `#5C5C5C`
- Primary `#111111`, accent `#E30613`, border `#C9C4BA`
- Radius `0px`, border width `1px`, shadow `none`
- Heading font: `Helvetica Neue, Helvetica, Arial, sans-serif`
- Body font: `Helvetica Neue, Helvetica, Arial, sans-serif`
- Base size: `16px`, display: `80px`
- Rhythm: unit `8`, sections ~`112px`, container ~`1180px`

## Map onto constructor blocks

1. **Header:** mark/logo, 3–5 links, secondary Sign in, primary CTA.
2. **Hero:** title + short body + dual CTAs + product media mock.
3. **Metrics:** 3–4 figures in a row — no fake theater.
4. **Features:** three cards; radius/shadow only from tokens.
5. **Pricing / FAQ / form:** inputs and buttons share border/radius; accent for the main form action.
6. Keep large even section spacing.

## Bans

- Soft shadow, blur, glassmorphism
- Rounded cards everywhere / скруглённые карточки везде
- Inter as a silent default
- Generic AI gradient washes
- Stickers over hero media

## Acceptance

1. Colors and radii match the tokens above.
2. No second palette "by taste".
3. Buttons and fields read as one family.
4. No horizontal scroll on mobile.
5. User content is unique — copy/photos change, the system does not.
