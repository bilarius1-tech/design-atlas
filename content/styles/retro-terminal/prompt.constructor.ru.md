# Промпт для конструктора · retro-terminal

Источник: DESIGN ATLAS · **Retro Terminal** (`retro-terminal`).
Блоки уже заданы пользователем — применяй только визуальную систему.

## Токены

- Фон `#0A0F0A`, текст `#33FF66`, янтарь `#FFB000`
- Рамка `#1C2A1C`, radius `0`, mono everywhere
- JetBrains Mono; display `57px`; контейнер `1040px`

## Наложение

1. CRT stage + scanlines; dashed phosphor frames.
2. Заголовки как `> commands`; CTA `[ label ]` янтарём.
3. Без neon-grid и без soft glass.
4. Не меняй структуру блоков пользователя.

## Запреты

- Midnight sans / neon-tech / Y2K / aurora
- Вторая палитра
