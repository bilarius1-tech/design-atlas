# Prompt · y2k

Implement an interface in the **Y2K** style using the DESIGN ATLAS system.

## Context

- Y2K: lavender ground, chrome headlines, acid pink/cyan, pills and double outlines.
- Page structure comes from the user’s chat — this prompt is visual system only.
- This is **not** neon-tech and **not** streetwear peach.

## Mandatory tokens

- background `#FDE7FF`, surface `#FFFFFF`, text `#2A0A3A`, muted `#6B4578`
- primary `#FF4FD8`, accent `#3DD6FF`, accentSecondary `#C0C0C0`, border `#FF4FD8`
- radius `24px`, radiusButton `999px`, radiusCard `28px`, borderWidth `2px`
- soft pink/cyan shadow; container `1080px`; display `57px`
- fonts: Unbounded headings, Nunito body

Display: chrome gradient + thin pink stroke. Glitter/stars sparingly.

## Bans

- Neon-tech dark grid
- Streetwear peach default
- Neo-brutal hard offset
- Dense-tile
- A second “taste” palette

## Acceptance

1. Lavender + chrome type + pink/cyan pills read immediately.
2. CTA contrast holds.
3. Values match `tokens.json`.
4. User structure is not rewritten.
