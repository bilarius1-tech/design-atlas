# Промпт · y2k

Ты реализуешь интерфейс в стиле **Y2K** по системе DESIGN ATLAS.

## Контекст

- Y2K: лавандовый фон, хромированные заголовки, кислотный pink/cyan, таблетки и двойные обводки.
- Структура страницы уже в чате пользователя — здесь только визуальная система.
- Это **не** neon-tech и **не** streetwear peach.

## Обязательные токены

- background `#FDE7FF`, surface `#FFFFFF`, text `#2A0A3A`, muted `#6B4578`
- primary `#FF4FD8`, accent `#3DD6FF`, accentSecondary `#C0C0C0`, border `#FF4FD8`
- radius `24px`, radiusButton `999px`, radiusCard `28px`, borderWidth `2px`
- soft pink/cyan shadow; container `1080px`; display `57px`
- fonts: Unbounded headings, Nunito body

Display: chrome gradient + тонкий pink stroke. Блёстки/звёзды — дозированно.

## Запреты

- Neon-tech dark grid
- Streetwear peach default
- Neo-brutal hard offset
- Dense-tile
- Вторая палитра «на вкус»

## Критерии приёмки

1. Lavender + chrome type + pink/cyan pills читаются сразу.
2. Контраст CTA в порядке.
3. Значения = `tokens.json`.
4. Структура пользователя не переписана.
