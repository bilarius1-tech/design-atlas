# Rules · y2k

## Do

1. Lavender ground `#FDE7FF`, ink `#2A0A3A`.
2. Pink `#FF4FD8` primary; cyan `#3DD6FF` secondary; chrome `#C0C0C0` for display metal.
3. Unbounded chrome headlines (`background-clip: text`); Nunito body.
4. Pill / blob radii; double outlines (white + pink/cyan).
5. Soft glitter dots; sticker accents sparingly.

## Don’t

1. Don’t default to neon-tech dark grids.
2. Don’t drift into streetwear peach + lime as the stage.
3. Don’t use neo-brutal 3px black hard offsets as the system.
4. Don’t cover every block with stickers until hierarchy dies.
5. Don’t invent a second palette outside `tokens.json`.

## Composition

- Default: `modular-stack`
- Structure from user chat; Atlas = visual system only
- Preview may add glitter dots + chrome type via scoped CSS

## Accessibility

- Ink on lavender ≥ AA
- Pink CTAs: white or deep purple labels that verify
- Chrome display needs stroke / contrast support
- Respect `prefers-reduced-motion`
