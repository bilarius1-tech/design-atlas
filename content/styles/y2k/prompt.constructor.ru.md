# Промпт для конструктора · y2k

Источник: DESIGN ATLAS · **Y2K** (`y2k`).
Блоки уже заданы пользователем — применяй только визуальную систему.

## Токены

- Фон `#FDE7FF`, панели `#FFFFFF`, текст `#2A0A3A`
- Primary `#FF4FD8`, cyan `#3DD6FF`, chrome `#C0C0C0`
- Карточки `28px`, кнопки pill, рамка `2px`
- Unbounded + Nunito; display `57px`; контейнер `1080px`

## Наложение

1. Лавандовый stage с лёгкими glitter-точками.
2. Display — chrome gradient; CTA pink или white+pink outline.
3. Двойные обводки и blob-радиусы; стикеры дозированно.
4. Не меняй структуру блоков пользователя.
