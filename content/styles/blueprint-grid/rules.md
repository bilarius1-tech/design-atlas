# Rules · blueprint-grid

## Do

1. Keep blue-graphite ground `#102631` with a fine cyan coordinate grid.
2. Cyan `#62D5FF` for primary; amber / lime as secondary markers only.
3. Roboto Mono for display and technical labels; Oswald/Manrope for body.
4. Small radii (4–6px); hairline borders; measured air.
5. Ordered composition — precision over campaign noise.

## Don’t

1. Don’t bloom into neon-tech acid glow.
2. Don’t invent dimension numbers or product specs in prompts.
3. Don’t use soft clay / neu / glass as the material.
4. Don’t switch to streetwear peach / Unbounded campaign energy.
5. Don’t invent a second palette outside `tokens.json`.

## Composition

- Default: `modular-stack`
- Structure from user chat; Atlas = visual system only
- Preview may add coordinate grid via scoped CSS

## Accessibility

- Light ink on graphite ≥ AA
- Cyan CTAs: prefer dark label if fill is bright enough, else outlined cyan on dark
- Respect `prefers-reduced-motion`
