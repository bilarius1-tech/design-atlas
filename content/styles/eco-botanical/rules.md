# Rules · eco-botanical

## Do

1. Warm kraft/paper ground `#EAE5D8`, ink `#34372C`.
2. Leaf green `#73865B` for primary; clay `#C47A4A` and honey `#D3A84B` sparingly.
3. Manrope / DM Sans with Cyrillic; friendly and clear.
4. Soft radii, airy gaps, tactile calm — not dense-tile.
5. Visual nature language only.

## Don’t

1. Don’t invent eco certificates, ingredient claims, or organic seals.
2. Don’t cold-shift into clinical blue or neon tech.
3. Don’t use streetwear loudness or clay 3D volume as the hero.
4. Don’t use thin low-contrast gray on kraft.
5. Don’t invent a second palette outside `tokens.json`.

## Composition

- Default: `modular-stack`
- Structure from user chat; Atlas = visual system only
- Preview may add soft botanical wash via scoped CSS

## Accessibility

- Ink on kraft ≥ AA
- Leaf green CTAs: cream/white labels
- Respect `prefers-reduced-motion`
