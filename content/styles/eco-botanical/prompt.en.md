# Prompt · eco-botanical

Implement an interface in the **Eco Botanical** style using the DESIGN ATLAS system.

## Context

- Natural eco presentation: kraft paper, leaf green, clay accents.
- Page structure comes from the user’s chat — this prompt is visual system only.
- Do not add eco certificates, ingredient claims, or organic seals the user did not provide.

## Mandatory tokens

- background `#EAE5D8`, surface `#F7F3EA`, text `#34372C`, muted `#6A6E5F`
- primary `#73865B`, accent `#C47A4A`, accentSecondary `#D3A84B`, border `#D4CDBB`
- radius `12px`, radiusButton `999px`, radiusCard `16px`, borderWidth `1px`
- soft shadow; container `1100px`; display `57px`; base `16px`
- fonts: Manrope headings; DM Sans body

## Bans

- Invented eco seals / ingredient claims
- Clinical / neon / streetwear drift
- Dense-tile as the hero
- A second “taste” palette

## Acceptance

1. Kraft + leaf/clay + friendly type read immediately.
2. CTA contrast holds.
3. Values match `tokens.json`.
4. User structure is not rewritten.
