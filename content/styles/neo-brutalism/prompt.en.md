# Prompt · neo-brutalism

Implement an interface in the **Neo-brutalism** style using the DESIGN ATLAS system.

## Context

- Neo-brutal: butter ground, thick black rules, hard no-blur offsets, pink/mint planes, Unbounded + Rubik.
- Page structure comes from the user’s chat — this prompt is visual system only.
- This is **not** `poster-brutal` (orange + Arial Black).

## Mandatory tokens

- background `#FFF4D6`, surface `#FFFFFF`, text `#111111`, muted `#4A4A4A`
- primary `#FF5C8A`, accent `#3DDC97`, accentSecondary `#FFD84D`, border `#111111`
- radius `8px`, radiusButton `6px`, radiusCard `8px`, borderWidth `3px`
- shadow `6px 6px 0 #111111`; container `1080px`; display `57px`; base `16px`
- fonts: Unbounded headings, Rubik body

Keep air around cards so hard offsets read. Not dense-tile.

## Bans

- Poster-brutal orange / Impact drift
- Soft blur, glass, neu inset
- Dense-tile / industrial flush
- Default white labels on pink/mint
- A second “taste” palette

## Acceptance

1. Butter + 3px black + hard offset + pink/mint read immediately.
2. Unbounded display, Rubik body.
3. Values match `tokens.json`.
4. User structure is not rewritten.
