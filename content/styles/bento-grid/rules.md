# Rules · bento-grid

## Do
1. Ground `#F5F5F7`, white tiles, ink `#1D1D1F`.
2. Gap `16px`, card radius `24px`, pill blue CTA.
3. 1–2 accent tiles (yellow/blue); one thought per tile.
4. Inter / Manrope / Onest.

## Don't
1. Don't build a Studio bento grid editor.
2. Don't use dense-tile `gap: 0` flush mosaics.
3. Don't crowd tiles with long paragraphs.
4. Don't invent a second palette.

## Composition
- Default: `modular-stack` (atmosphere only)
- Uneven spans expressed in prompts/CSS, not a page builder
