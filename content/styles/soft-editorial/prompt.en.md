# Prompt · soft-editorial

Implement an interface in the **Soft Editorial** style using the DESIGN ATLAS system.

## Context

- Calm journal system: warm paper, Playfair, soft terracotta / sage accents.
- Page structure comes from the user’s chat — this prompt is visual system only.

## Mandatory tokens

- background `#F5F1E9`, surface `#FFFFFF`, text `#302B27`, muted `#6F6860`
- primary `#B57956`, accent `#7D8C72`, accentSecondary `#7A8FA3`, border `#E0D9CE`
- radius `8px`, radiusButton `999px`, radiusCard `12px`, borderWidth `1px`
- soft shadow; container `1080px`; display `57px`; base `16px`
- fonts: Playfair Display headings; Manrope body

Air and short headlines. No dense-tile. No fake logos.

## Bans

- Dense-tile / industrial 0-gap
- Neon / streetwear / clay
- Stickers and invented fashion marks
- A second “taste” palette

## Acceptance

1. Paper + Playfair + soft accents read immediately.
2. CTA contrast holds.
3. Values match `tokens.json`.
4. User structure is not rewritten.
