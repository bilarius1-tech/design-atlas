# Rules · soft-editorial

## Do

1. Warm paper ground `#F5F1E9`, ink `#302B27`.
2. Terracotta `#B57956` for primary; sage/slate as soft secondary signals.
3. Playfair Display for headings; Manrope for body with Cyrillic.
4. Keep air — wide margins, soft shadows, no dense-tile flush mosaics.
5. Short expressive headlines; accents in thin markers only.

## Don’t

1. Don’t use dense-tile / 0-gap industrial mosaics.
2. Don’t invent fashion logos or sticker clutter.
3. Don’t drift into neon / streetwear / clay soft volume.
4. Don’t use thin low-contrast gray on warm paper.
5. Don’t invent a second palette outside `tokens.json`.

## Composition

- Default: `editorial-split`
- Structure from user chat; Atlas = visual system only

## Accessibility

- Ink on paper ≥ AA
- Terracotta CTAs: prefer cream/white labels when fill is dark enough
- Respect `prefers-reduced-motion`
