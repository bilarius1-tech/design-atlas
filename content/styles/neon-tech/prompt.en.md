# Prompt · neon-tech

Implement an interface in the **Neon Tech** style using the DESIGN ATLAS system.

## Context

- Dark tech stage: charcoal ground, fine grid, controlled neon glow.
- Type: Unbounded (display), Oswald / Manrope (body), Roboto Mono (captions).
- Page structure comes from the user’s chat — this prompt is visual system only.

## Mandatory tokens

- background `#171A22`, surface `#222633`, text `#F4F4F8`, muted `#9AA0B2`
- primary `#B6FF00`, accent `#00D5FF`, accentSecondary `#FF4FD8`, border `#34384A`
- radius `8px`, radiusButton `8px`, radiusCard `12px`, borderWidth `1px`
- shadow: soft dark + subtle lime/cyan glow
- container `1120px`, display `57px`, base `16px`

Primary CTA: lime fill with **dark** label. Neon is contours and markers, not a full-bleed wash.

## Bans

- Frosted glass as the main material
- Clay / neu soft volume
- White text on lime
- Invented ports, logos, or cyber noise over content

## Acceptance

1. Dark stage reads; neon stays controlled.
2. CTAs pass contrast (dark ink on lime).
3. Values match `tokens.json`.
4. User structure is not rewritten.
