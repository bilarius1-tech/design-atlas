# Agent instructions · claymorphism

1. Read `DESIGN.md` and `tokens.json` before coding.
2. Apply **visual system only** — page structure comes from the user’s chat / brief.
3. Prefer CSS variables from tokens; do not invent a second palette.
4. Keep button radius and card radius separate (`radiusButton` vs `radiusCard`).
5. Dual soft shadow is identity — do not replace with hard neo-brutal offsets.
6. Preserve Cyrillic-capable Nunito / Manrope stacks.
7. Verify focus-visible and mobile widths (390 / 768 / 1440).
