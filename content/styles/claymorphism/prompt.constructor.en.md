# Constructor prompt · claymorphism

You are assembling a landing in a **page constructor** (Tilda, LPmotor, Creatium, Kraftum, or similar) or via a constructor agent.
Visual system source: DESIGN ATLAS · **Claymorphism** (`claymorphism`).

## Core rule

Do not invent a second design system. Blocks and order are already set by the user — Atlas supplies the visual system only.

## Mandatory tokens

- Background `#F4EEFF`, surface `#FFFCFF`, text `#2B2140`, muted `#6B5F8A`
- Primary `#7C5CFF`, accent `#FFB86B`, border `#E4D9F7`
- Radius `28px`, buttons `999px` (pill), cards `32px`, border `1px`
- Shadow: `10px 14px 32px rgba(124, 92, 255, 0.22)` + light inset
- Fonts: Nunito (headings), Manrope (body) with Cyrillic — else closest system analog
- Base `16px`, display `57px`
- Rhythm: unit `8`, sections ~`104px`, container ~`1200px`

## Map onto constructor blocks

1. Cards lighter than the ground, large radius, soft dual shadow.
2. Buttons plump / near-pill; primary violet, secondary outline/peach.
3. Form fields share the radius family — no sharp corners.
4. Do not change the user’s section structure.

## Bans

- Hard neo-brutal offsets
- Dark tech console
- Inter by default
- Flat hairline cards

## Check

1. Colors and radii match tokens.
2. Buttons and cards feel one volume family.
3. No second “taste” palette.
4. No horizontal scroll on mobile.
