# Rules · claymorphism

## Do

1. Keep the pastel lavender ground (`#F4EEFF`); lift cards with soft dual shadow, not hard borders.
2. Use large radii: cards ~`32px`, buttons plump / near-pill.
3. Primary violet (`#7C5CFF`) for main actions; peach accent (`#FFB86B`) for warmth — not neon.
4. Headings in Nunito (heavy), body in Manrope; keep Cyrillic support.
5. Friendly consumer tone — soft icons, rounded media frames.

## Don’t

1. Don’t flatten into Material hairline cards.
2. Don’t switch to neo-brutal hard offsets or pure glass blur as identity.
3. Don’t default to Inter or sharp 0–4px radius systems.
4. Don’t darken the whole page into a console theme.
5. Don’t invent a second palette outside `tokens.json`.

## Composition

- Default composition id: `modular-stack`
- Studio templates supply structure; this pack supplies atmosphere
- Markdown token tables must mirror `tokens.json`

## Accessibility

- Verify `#2B2140` on pastel surfaces (AA)
- Visible `:focus-visible` on plump controls
- Respect `prefers-reduced-motion` for hover scale
