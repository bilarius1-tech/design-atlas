# Промпт для конструктора · claymorphism

Ты собираешь лендинг в **конструкторе** (Тильда, LPmotor, Creatium, Kraftum и аналоги) либо через агента конструктора.
Источник визуальной системы: DESIGN ATLAS · **Claymorphism** (`claymorphism`).

## Главное правило

Не изобретай вторую дизайн-систему. Блоки и порядок уже заданы пользователем — Atlas даёт только визуальную систему.

## Токены (обязательны)

- Фон `#F4EEFF`, поверхность `#FFFCFF`, текст `#2B2140`, muted `#6B5F8A`
- Primary `#7C5CFF`, accent `#FFB86B`, border `#E4D9F7`
- Радиус общий `28px`, кнопки `999px` (pill), карточки `32px`, линия `1px`
- Тень: `10px 14px 32px rgba(124, 92, 255, 0.22)` + светлый inset
- Шрифты: Nunito (заголовки), Manrope (текст) — с кириллицей; иначе ближайший системный аналог
- Базовый текст `16px`, display `57px`
- Ритм: unit `8`, секции ~`104px`, контейнер ~`1200px`

## Как накладывать на блоки

1. Карточки — светлее фона, большой радиус, мягкая двойная тень.
2. Кнопки — «надутые», почти pill; primary violet, secondary outline/peach.
3. Поля форм — тот же радиус семьи, без острых углов.
4. Не меняй структуру секций пользователя.

## Запреты

- Hard neo-brutal offsets
- Тёмная tech-консоль
- Inter по умолчанию
- Плоские hairline-карточки

## Проверка

1. Цвета и радиусы совпадают с токенами.
2. Кнопки и карточки — одна семья объёма.
3. Нет второй палитры «на вкус».
4. На мобиле нет горизонтального скролла.
