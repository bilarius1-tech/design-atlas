# Промпт для конструктора · glassmorphism

Источник: DESIGN ATLAS · **Glassmorphism** (`glassmorphism`).
Блоки уже заданы пользователем — применяй только визуальную систему.

## Токены

- Фон `#0F1B4C`, панели `rgba(255,255,255,0.12)`, текст `#FFFFFF`
- Primary `#7F5AF0`, accent `#2CB1FF`, border `rgba(255,255,255,0.3)`
- Карточки radius `20px`, кнопки pill, blur ~16px
- Шрифт Manrope / Golos Text (кириллица)
- Display `57px`, контейнер `1140px`

## Наложение

1. Секции/карточки — стекло: alpha + blur + светлая рамка.
2. Фон — тёмно-синий с мягкими violet/cyan пятнами.
3. CTA — violet; вторичные — стеклянный outline.
4. Не меняй структуру блоков пользователя.

## Запреты

- Плотные непрозрачные карточки
- Neu / clay drift
- Вторая палитра «на вкус»
